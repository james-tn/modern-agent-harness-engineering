# Interactive briefing

Generate a self-contained HTML artifact with inline SVG. Include:

- event summary and effective trading date;
- security, benchmark, and abnormal-return series;
- exposure band, not restricted position fields;
- thesis confirmation and challenge signals;
- visible assumptions, uncertainty, methods, and evidence IDs.

Every plotted value must be present in the machine-readable analysis output.
