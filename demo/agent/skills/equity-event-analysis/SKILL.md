# Equity event analysis

Use this skill for earnings, guidance, filing, and other discrete equity events.

1. Create a plan before retrieval or calculation.
2. Retrieve primary public evidence and the approved internal methodology.
3. Determine the effective trading event date from the announcement timestamp.
4. Use adjusted prices and the policy-approved benchmark.
5. Separate reported facts, management guidance, external commentary, and inference.
6. Generate the analysis with executable code.
7. Require verifier admission and human approval before publishing.

Never issue investment advice. The output is a research-process demonstration.
