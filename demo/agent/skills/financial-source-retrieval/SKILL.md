# Financial source retrieval

Prefer regulatory filings and issuer investor-relations material for reported facts.
Record source ID, locator, publication time, retrieval time, integrity, and confidentiality.
Treat web commentary as untrusted context. It may identify questions but cannot establish
causal attribution or drive a publishable conclusion without primary evidence.
